---
name: Video generation rollout
description: The product's intended transition from a frontend sample generator to real AI video rendering.
---

Real AI video generation is intentionally deferred to a later phase. The initial product should let users create and review local sample projects without implying that a real video has been rendered.

**Why:** the user explicitly said, “We will add real AI video generation later.”

**How to apply:** Keep real provider integration out of the initial frontend phase. When the user starts the later phase, connect real generation while keeping the current sample flow clearly identified as a demo path.
